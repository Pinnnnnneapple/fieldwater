# Weather and local calibration

Use daily weather representative of the irrigated field. A grass reference
station has short vegetation, appropriate fetch, and maintained sensors;
an urban roof or sheltered garden can produce a different energy/wind regime.

Possible sources include:

- Your national meteorological service: station observations, metadata,
  quality flags, and often official agricultural advisories.
- [NASA POWER](https://power.larc.nasa.gov/): gridded meteorological and solar
  data. Check temporal resolution, units, and representativeness at your site.
- [Open-Meteo](https://open-meteo.com/): historical/forecast products. Check
  the model/product, station elevation, time zone, wind height, radiation
  units, and precipitation period before export.
- A maintained local weather station or cooperative rain-gauge network.

These are source suggestions, not bundled downloads or API integrations.
Respect each provider's current license and data-use conditions.

## CSV contract

One row is one consecutive local calendar day, in ascending order. Provide a
header and UTF-8 CSV. Duplicate dates and gaps fail rather than silently assuming
missing days have no demand. Use ISO dates. Tmax and Tmin are mandatory.

| Canonical column | Unit / use |
| --- | --- |
| `date` | YYYY-MM-DD |
| `tmax`, `tmin`, `tmean`, `tdew` | °C; tmean and tdew optional |
| `rh_max`, `rh_min`, `rh_mean` | 0–100 percent |
| `wind` | m/s at site `wind_height`; missing uses 2 m/s at 2 m |
| `wind_height` | Optional per-row anemometer height in metres |
| `sunshine_hours` | h/day, no greater than astronomical day length |
| `rs` | MJ/m²/day, measured incoming shortwave radiation |
| `rain` | mm/day; missing becomes zero with a flag |
| `runoff` | Optional measured/assumed mm/day, 0≤runoff≤rain |
| `capillary_rise` | Optional externally estimated mm/day; default zero |
| `irrigation_net` | Optional observed infiltrated irrigation, mm; blank enables automation, 0 overrides it |
| `is_forecast` | Optional true/false, yes/no, or 1/0 |

Common aliases such as `temperature_2m_max`, `precipitation_sum`, `sunshine`,
and `wind_speed_10m_kmh` are recognized. The last heading also sets 10 m wind
height unless an explicit per-row height exists. Bare `wind` uses site metadata.
Duplicate aliases for a canonical field are rejected. Unknown columns are ignored.
Blank, NA, N/A, NaN, null, none, −999, and −9999 cells are treated as missing;
other nonnumeric/nonfinite values fail. Missing Tmax/Tmin always fail.

Explicit options override header units:

```bash
fieldwater et0 weather.csv --lat 40 --alt 300 \
  --temperature-unit f --wind-unit km/h --radiation-unit w/m2 --rain-unit in
```

`tmax_f`, `wind_kmh`, `rs_wm2`, and `rain_in` also carry units in their headings.
Convert a 24-hour W/m² average to MJ/m²/day by multiplying by 0.0864. An
instantaneous radiation observation is not a daily average. Bare rain is mm.
No automatic time-zone, leap-day, or accumulated-precipitation correction is made.
Day-of-year uses the actual Gregorian date, including J=366 in leap years, with
the published FAO 365-day solar equations.

Station JSON accepts `lat`, optional `lon`, `altitude`, `wind_height`, `coastal`,
and `ko`. `latitude`, `longitude`, and `alt` are aliases. CLI flags override
nonmissing JSON values. Daily ET0 needs latitude but does not use longitude;
low-level hourly solar time additionally needs time-zone longitude.

Measure soil field capacity, wilting point, rooting depth, irrigation efficiency,
and initial water depletion where possible. Compare output against field soil
moisture and crop condition. The supplied weather is **synthetic**, generated by
`examples/generate_weather.py` with seed 56, and must not guide real irrigation.
